# GMB Media Inbox

Esta carpeta es un buzón temporal para compartir videos y fotografías a procesar en las publicaciones de Google My Business (GMB / GBP) de **Narbo's Salón Spa**.

### Flujo de trabajo:
1. Coloca aquí los videos o imágenes que desees analizar para redactar el post.
2. Todo el contenido multimedia colocado en esta carpeta está ignorado por `.gitignore` y **no se subirá a GitHub**.
3. Una vez generado y publicado el post, retira o elimina los videos de esta carpeta para mantener el espacio limpio.
